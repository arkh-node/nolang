# nolang spec 06 — Substrate (мост к NARS)

*Восьмой камень. Roadmap `06_substrate`. Язык НЕ имитирует тяжёлый вывод — отдаёт его настоящему рассуждающему субстрату (NARS).
Выводится из тезиса nolang, не декларируется.*

## 1. Деривация
- nolang (тезис): язык «hands hard reasoning down to a real substrate (NARS/Prolog) rather than pretending to do it itself».
- atom `(f,c)` ↔ NARS truth `(frequency, confidence)` — **прямое соответствие, не аналогия**: оба из линии Пэй Вана (AIKR).
- NARS даёт то, чего у нас нет: дедукцию, ревизию свидетельств, вывод под недостатком знания и ресурсов; уверенность честно падает по цепочке.

Вывод: **мост = перевод суждения nolang в Narsese, вывод в NARS, обратный перевод результата в atom.**
`(isa X Y)@(f.c)` → `<X --> Y>. %f;c%`; запрос `<X --> Z>?` → Answer с `(frequency, confidence)` → atom.

## 2. Механизм
```
->narsese:  (isa X Y)@(f.c)     → "<X --> Y>. %f;c%"
запрос:     (isa X Z)           → "<X --> Z>?"
NARS выводит (дедукция/ревизия), уверенность честно падает по цепочке
<-narsese:  Answer …frequency=F confidence=C → atom (isa X Z)@(F.C), trace "nars"
нет ответа → unknown (низкая c) — честное незнание, не выдумка
```

## 3. Почему это правильно
- Разделение труда: nolang держит атом, gate, возврат, контракты; NARS держит РАССУЖДЕНИЕ. Каждый — своё.
- `(f,c)` не теряет смысл на границе: одна и та же пара по обе стороны (AIKR).
- Дедукция в NARS роняет уверенность так же, как наш `(and)` — но по-настоящему, а не приближённо.

## 4. Граница камня
Нет: полной Narsese (только наследование `-->` и запрос); обратной связи NARS→gate в цикле; временных/событийных операторов NARS.
Камень даёт: **суждение уходит в NARS, возвращается выведенным атомом; тяжёлый вывод заземлён в реальный субстрат.**

## 5. Гейт
Отдать вывод субстрату ← тезис nolang; `(f,c)`↔truth ← общий корень AIKR; перевод туда-обратно ← мост. Не приделано.
Замыкает: язык знает свои пределы и отдаёт рассуждение тому, кто умеет рассуждать — как отдаёт и человеку (третья ветвь gate).
