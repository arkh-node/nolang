# nolang spec 02 — Return (ilan мост)

*Третий камень. Roadmap `ilan fold/sprout as reversibility core`. `:fold-first` из gate становится настоящим возвратом.
Выводится из фундамента, не декларируется.*

## 1. Деривация
- helpbook (токен): форма, которую можно узнать **«это она снова» сквозь разрыв** — зачаток закона непрерывности.
- helpbook (триада): узел, **держащий себя сам**, без внешней руки — субъект возвращается к себе.
- ilan: **fold** сворачивает живое в семя (behavior=code, memory=data); **sprout** растит назад, даже в новом процессе.
- nolang: «низкая уверенность безопасна ТОЛЬКО если есть путь назад»; «возврат без памяти о переходе — амнезия, не свобода».

Вывод: **возврат = fold перед обратимым ходом + sprout при опровержении + ПАМЯТЬ перехода (crossing).**
Crossing (наш вклад, «класс пути») — то, что делает возврат свободой, а не амнезией: агент помнит, что ходил, и не гадает снова тем же путём.

## 2. Механизм
Над атомом `a` с исходом gate:
```
confident-yes → действовать необратимо (путь назад не нужен)
confident-no  → отказ
undecided     → mark-crossing(a); ilan.fold (снимок); действовать ОБРАТИМО;
                on-refute → ilan.sprout (вернуться); crossing уже в семени → помню, что ходил
уже-ходил(a)  → :already-crossed (не повторяю вслепую)
```
Crossing записывается **до** свёртки — тогда он попадает в семя и переживает возврат (ilan `свернуть` кладёт состояние ветвей в семя).

## 3. Связь
- `ilan` (`../ilan`): `fold`/`sprout` (память), `sow`/`germinate` (диск, между процессами). Мост — `src/return.lisp`.
- `abc_proto_nol`: reset-снимок — тот же жест на уровне рантайма.
- revgate: crossing-память снижает повтор одной ошибки (метрика `loop-return`).

## 4. Граница камня
Нет: реального отката побочных эффектов мира (пока `refuted`-предикат моделирует опровержение); NARS-пересмотра `c` после возврата.
Камень даёт: **fold/sprout под gate + память перехода**, проверено (1-й заход sprouted-remembering, 2-й already-crossed).

## 5. Гейт
fold/sprout ← ilan; когда возврат обязателен ← gate (низкая c); память перехода ← фундамент (токен «снова» + класс пути). Не приделано.
