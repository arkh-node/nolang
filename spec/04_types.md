# nolang spec 04 — Types (контракты и capability-эффекты)

*Седьмой камень. Roadmap `04_types`. Действие перестаёт быть голым «обратимо/необратимо» и несёт контракт:
что оно ТРЕБУЕТ и что ДАЁТ. Выводится из фундамента (helpbook: «типы как контракты»), не декларируется.*

## 1. Деривация
- helpbook (типы как контракты): тип — не ярлык, а обязательство формы; действие обязано объявить условия и следствие.
- atom (камень 00): предусловия — это суждения с `(f,c)`; «держится» значит confident-yes.
- gate (камень 01): класс действия допускается по уверенности. Контракт связывает: *действие дозволено ⇔ его предусловия держатся*.

Вывод: **контракт действия = (требует · класс · даёт)**, где `требует` — суждения-предусловия,
`класс` — reversible/irreversible, `даёт` — суждение-эффект (новое знание после выполнения).
Capability = гарантия: действие данного класса дозволено только когда все предусловия confident-yes.

## 2. Механизм
```
контракт = (требует=[j…] · класс · даёт=j')

проверить(требует):
  все confident-yes           → :ok
  какое-то undecided          → (:route j)     ; не хватает уверенности — доуточнить, не действовать
  какое-то confident-no       → (:unmet j)     ; предусловие ложно — действие недопустимо

выполнить(контракт):
  :ok  → допуск по классу (gate) → сделать → добавить `даёт` в знание (эффект)
  route / unmet → не выполнять; вернуть причину
```
Так «незнание предусловия» не проваливает действие в догадку, а честно останавливает его на маршрут к проверке.

## 3. Capability-эффект
После успешного действия его `даёт` становится новым атомом в базе знаний — с провенансом «действие такое-то».
Знание растёт не произвольно, а как след дозволенных действий. Это связывает типы (что действие даёт) с провенансом (камень 03).

## 4. Граница камня
Нет: параметрических/зависимых типов, вывода контракта (пока контракт объявлен явно), проверки эффектов на согласованность.
Камень даёт: **контракт над действием — предусловия проверяются, класс гейтится, эффект пополняет знание; незнание → route.**

## 5. Гейт
Контракт-как-обязательство ← helpbook(типы); предусловия-суждения ← atom; допуск ← gate; эффект-в-знание ← провенанс eval. Не приделано.
