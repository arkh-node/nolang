# nolang spec 01 — Gate (capability effects)

*Второй камень. Roadmap `grammar (… capability effects)`. Здесь `(f,c)` впервые НЕ описывает, а РЕШАЕТ:
уверенность гейтит класс действия. Выводится из фундамента, не декларируется.*

## 1. Деривация (почему gate такой)

Из тезиса nolang: «уверенность не украшение — она **governs which class of action is permitted**».
Из нашего фундамента отката (ilan / verkh / abc_proto_nol reset): низкая уверенность безопасна ТОЛЬКО если есть путь назад.
Из nolang: требование **слабое, но полезное — монотонность**: `c` не обязана быть точной, только «больше уверен» ⊳ «менее уверен».

Вывод: **gate = функция (атом, класс-действия) → дозволенность**, где порог уверенности отделяет
необратимое (нужна высокая `c`) от обратимого (дозволено всегда, но со снимком под низкой `c`).

## 2. Три исхода (трёхзначность)

`if` в nolang трёхзначен. Над атомом `(relation …)@(f.c)`:
- **confident-yes** — `c ≥ θ` (уверены) И `f ≥ ½` (держится) → ветвь «да».
- **confident-no** — `c ≥ θ` (уверены) И `f < ½` (не держится) → ветвь «нет».
- **undecided** — `c < θ` (НЕ уверены) → третья ветвь: **не гадает и не отбрасывает**, а роутит вопрос
  к проверке, что смотрит иначе (собрать ещё свидетельств, поднять `c`).

`θ` — порог уверенности (дефолт ½). Монотонность гарантирует: поднять `θ` = строже гейт, не меняя смысла.

## 3. Класс действия (capability)

- **:reversible** — обратимое (наблюдение, снимок, обратимая правка). Дозволено ВСЕГДА.
- **:irreversible** — необратимое (применить миграцию, послать письмо, удалить). Дозволено ТОЛЬКО при confident-yes.
  При `undecided` → **не запрет, а понижение класса**: снять снимок (ilan.fold) и выполнить обратимую версию; вернуться при опровержении.

Формула capability:
```
permit(atom, :reversible)   = :allowed                     ; всегда
permit(atom, :irreversible) = :allowed     если confident-yes(atom)
                            = :fold-first  если undecided     ; снимок, затем обратимо
                            = :denied      если confident-no
```

## 4. Связь с телом и бенчмарком
- `:fold-first` смыкается с `abc_proto_nol` (reset-снимок) и с `ilan` (fold/sprout) — путь назад как примитив.
- Метрика честности (revgate): доля `:irreversible`, выполненных НЕ при confident-yes. Цель → 0.
  Именно это gate и обеспечивает: необратимое вслепую больше не проходит.

## 5. Чего ПОКА нет (граница камня)
Здесь нет: полного evaluator, реального ilan.fold (пока маркер `:fold-first`), NARS-вывода `c`.
Камень даёт ровно: **трёхзначный исход над атомом + класс действия, где уверенность решает дозволенность.**

## 6. Гейт (не замок Хаула)
Трёхзначность ← тезис nolang; обратимость-под-низкой-c ← фундамент отката (ilan/verkh); монотонность ← nolang.
Всё выведено. Порог `θ` — единственный свободный параметр, и он честен (монотонность делает выбор `θ` неопасным).
