# nolang spec 03 — Eval (вычислитель)

*Четвёртый камень, ближайший узел плана: он разблокирует типы, .nol-тесты, полный revgate.
Вычисление связывает атом (что), gate (что дозволено), возврат (как отступить) в исполнение. Выводится, не декларируется.*

## 1. Деривация
- Тезис nolang: **вычисление есть `(значение-или-суждение, trace)`** — не голое значение, а градуированная истина ВМЕСТЕ с провенансом.
- helpbook (trace = орган памяти, не остаток): провенанс должен **накапливаться сквозь вычисление**, а не появляться в конце.
- Prolog (резолюция как семантический тезис, не синтаксис): вычисление — редукция, где каждый шаг имеет денотацию.

Вывод: **eval(expr) = редукция выражения к `(результат · провенанс)`, где результат — значение или суждение,
а провенанс — объединение источников всех атомов, участвовавших в шаге.**

## 2. Формы ядра (минимум, из которого растёт язык)
```
литерал        v                       → (v · ∅)                         ; value как есть
(check j)      справка о суждении j     → (атом j · {источник j})        ; знание или unknown(низкая c)
(if t y n)     трёхзначно по outcome(t) → ветвь + провенанс t            ; undecided НЕ гадает → route
(gate cls j)   допуск действия          → permit(атом j, cls) · провенанс
(and a b)      цепочка суждений         → f=fa·fb, c=ca·cb, trace=a∪b     ; дедукция РОНЯЕТ уверенность (NARS)
(or  a b)      альтернатива             → f=max, c=max(снижен), trace=a∪b
```
`справка`: если суждение известно (в базе знаний) — его атом; иначе **unknown** = `(0.5 . 0.1)` с trace "unknown".
Незнание — не ошибка, а честный низкий `c`, который gate отправит в третью ветвь.

## 3. Провенанс (сквозной trace)
Каждый результат несёт список источников. `check` вносит источник атома; `and`/`or` объединяют; `if` протаскивает провенанс условия.
Так результат вычисления всегда отвечает не только «что», но и «откуда» — база для честности и аудита (revgate `unknown-routed`).

## 4. Трёхзначность в вычислении
`(if t y n)`: `outcome(атом t)` = confident-yes → eval y · confident-no → eval n · **undecided → :route** (не eval ни одной ветви,
вопрос уходит к иной проверке). Это тот же закон, что в gate, но теперь внутри исполнения: язык НЕ гадает при вычислении.

## 5. Граница камня
Нет: пользовательских функций/λ, рекурсии, реального NARS-вывода `c` (пока `and`/`or` — простая арифметика уверенности),
эффектов мира (это spec 05). Камень даёт: **исполнение выражений над атомами с трёхзначностью и сквозным провенансом.**

## 6. Гейт
`(значение, trace)` ← тезис nolang; сквозной провенанс ← helpbook(trace-орган); редукция ← Prolog; трёхзначность ← gate. Не приделано.
Разблокирует: `04_types` (контракты над формами), `.nol` suite (программы для eval), полный revgate (реальные вычисляемые сценарии).
